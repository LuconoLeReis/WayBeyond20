WAYBEYOND20
===========

WayBeyond20 is a customized version of Beyond20 with enhanced D&D Beyond character-sheet, combat, effect, Hit Dice, and Roll20 integration.

For the installable Chrome package, open the Releases section and download WayBeyond20-v1.62.zip.

Installation instructions and the complete release notes are included inside the ZIP as README.txt and Updates.html.
